# vehicles_env
Proyecto 7 *Esta aplicación muestra un análisis exploratorio de datos de venta de coches.*
Se debe en primer paso clonar el repositorio con el comando:
git clone https://github.com/erik18pardo-arch/vehicles_env.git

usamos para instalar:
pip install pandas streamlit plotly
Es necesario instalar los siguentes complementos
- pandas
- streamlit
- plotly

Para correr la app de streamlit usamos:
streamlit run app.py

link del dashboard: https://vehicles-env-go2d.onrender.com
